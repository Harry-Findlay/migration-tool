PMS Data Import
Import a patient CSV exported from your PMS, compare it against the source data, and map any mismatched fields before migration
Step 1 — Load PMS CSV
Export a patient list from your PMS software as a CSV file. The file should include at minimum: patient surname, first name, and date of birth. NHS number, patient reference, and address fields will be used for matching if present.
Drop CSV file here, or click to browse
Supports .csv files exported from any PMS
Step 2 — Map CSV Columns
Match each standard field to the corresponding column in your CSV. Fields marked Required must be mapped to proceed.
Step 3 — Compare PMS vs Source
PMS Surname PMS First Name PMS DOB PMS Ref Match Source Surname Source First Name Source DOB Conflicts
Step 4 — Resolve Conflicts
For each conflict below, choose which value to use during migration — the PMS value or the Source value. You can also enter a corrected value manually.
Step 5 — Choose Data Source for Migration
📋
Use PMS Data
Patient demographic fields (name, DOB, NHS number) taken from the PMS CSV. Imaging data comes from the source system.
🗄️
Use Source Data
All patient data taken directly from the imaging source system. PMS CSV used for reference matching only.
🔀
Merged (PMS fills gaps)
Source data is primary. Any empty or missing fields are filled from the PMS CSV where a match exists.
